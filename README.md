# BrightSmile Dental Clinic — Demo Website
A demo dental clinic website built as a design sample for client outreach. The business shown is fictional and all contact details are placeholders.
## Purpose
Shows the quality of a modern small-business website — treatments, appointment booking, contact section, mobile-friendly layout — offered to real clinics as a free demo homepage.
## Tech
Single self-contained static HTML file (index.html). No build step — deploy as-is on any static host.
